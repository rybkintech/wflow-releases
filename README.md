# WFlow

Диктовка голосом в любое поле ввода на macOS. Удерживаешь клавишу и говоришь — текст появляется там, где стоит курсор. Распознавание локальное: звук не покидает Mac.

## Установка

1. Скачай [WFlow.dmg](https://github.com/rybkintech/wflow-releases/releases/latest/download/WFlow.dmg).
2. Открой образ и перетащи WFlow в «Программы».
3. При первом запуске разреши «Микрофон» и «Универсальный доступ» — приложение само проведёт по шагам.

Нужен Mac на Apple Silicon и macOS 13 или новее. Модель распознавания (574 МБ) скачивается при первом запуске.

Сборка подписана, но не нотаризована Apple, поэтому при первом запуске macOS предупредит о неизвестном разработчике. Открыть можно так: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

Дальше приложение обновляется само.

В этом репозитории лежат только сборки.
